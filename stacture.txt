1. Libraries & Versions Used
----------------------------
Based on package.json, here are the libraries and their versions:

Dependencies (Main Packages):
- react (^19.2.6)              : The core React library for building user interfaces.
- react-dom (^19.2.6)          : Entry point for DOM and server renderers for React.
- react-router-dom (^7.15.1)   : Library used for routing and multi-page navigation.
- framer-motion (^12.40.0)     : Used for creating smooth animations and transitions.
- react-icons (^5.6.0)         : Provides a collection of popular icons (FontAwesome, Material, etc.).
- lucide-react (^1.16.0)       : Additional icon library with clean, consistent SVG icons.
- clsx (^2.1.1)                : A tiny utility for conditionally joining class names.
- tailwind-merge (^3.6.0)      : Merges Tailwind CSS classes without style conflicts.
- qrcode.react (^4.2.0)        : React component for generating QR codes.
- @vercel/speed-insights (^2.0.0) : Vercel analytics for performance monitoring.

DevDependencies (Tools & Plugins):
- vite (^8.0.12)               : Fast frontend build tool and development server.
- @vitejs/plugin-react (^6.0.1): Vite plugin for React support.
- tailwindcss (^4.3.0)         : Utility-first CSS framework for rapid UI development.
- @tailwindcss/vite (^4.3.0)   : Vite plugin for Tailwind CSS integration.
- @types/react (^19.2.14)      : TypeScript types for React.
- @types/react-dom (^19.2.3)   : TypeScript types for React DOM.
- eslint (^10.3.0) & plugins   : Used for linting and enforcing code quality.
- globals (^17.6.0)            : Global variables for ESLint environments.


2. Project Folder & File Structure (What is inside what)
--------------------------------------------------------

ALLPVAUSA/
|-- package.json              -> Contains metadata, dependencies, and scripts for the project.
|-- package-lock.json         -> Locks the exact versions of dependencies installed.
|-- vite.config.js            -> Configuration file for Vite.
|-- eslint.config.js          -> Configuration for ESLint (code linting).
|-- index.html                -> Main HTML file. The entry point of the React app (contains <div id="root">).
|-- stacture.txt              -> This file. Documents project structure and dependencies.
|
|-- public/                   -> Static assets served directly (no processing by Vite).
|   |-- favicon.svg           -> Website favicon icon.
|   |-- icons.svg             -> SVG icon sprite file.
|
|-- src/                      -> All source code for the React application.
    |-- main.jsx              -> Main React entry point. Imports App.jsx and mounts it to the DOM.
    |-- App.jsx               -> Root component. Handles all routing, themes, and overall app structure.
    |-- index.css             -> Global CSS file. Includes Tailwind CSS directives and global variables.
    |-- App.css               -> App-specific CSS styles.

    |-- assets/               -> Images and static files used inside React components.
